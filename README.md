# Personal CV Website

## About the Project

This project is a simple personal Curriculum Vitae (CV) website developed using HTML and CSS. It presents personal information, contact details, educational qualifications, skills, and professional experience in a structured and visually organized layout.

## Features

- Personal profile section
- Contact information
- Educational qualifications
- Personal details
- Skills and experience sections
- Clean and organized CV layout

## Technologies Used

- HTML5
- CSS3

## Project Structure

```text
cv/
│
├── images/
├── index.html
├── styles.css
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. View the CV website.

## Purpose

This project was developed to practice HTML and CSS skills while creating a simple and structured online CV.
